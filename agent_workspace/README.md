# agent_workspace — agent 的工作区

**这里是 agent 干活的地方，也是它的"家"。**

## 约定

- **每个任务一个子文件夹**，不要在工作区根目录散落文件。
- 子文件夹命名清晰描述任务内容（如 `数据可视化实验一`、`劳动实践`）。
- 任务相关的所有文件（代码、文档、资源）都放在对应子文件夹内。

## 与 git 的关系

工作区产出默认**不入库**（见根 `.gitignore`）—— 那是本机资产，不是项目源码。
想提交某个任务产物时，用 `git add -f <path>` 单独放行。

## 子目录速览

| 目录 | 用途 |
|---|---|
| `.tmp_exec/` | 执行类工具（`execute_python` / `execute_shell`）的临时落点，不入库 |
| 其它 | 按任务自由创建 |
