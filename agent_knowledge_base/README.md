# agent_knowledge_base — RAG 语料库

往这里放 `.md` 文件，agent 就能通过知识库工具（`agent_tools/rag.py`）检索它们。

## 用法

- **语料格式**：Markdown 文本（`.md`）
- **入库时机**：由 agent 的知识库工具在运行时读取并写入向量库（`chroma_db/`，本机产物，不入库）
- **首次使用会冷启动**：向量模型需要先加载，第一次检索可能触发超时，再问一次即可

## 现状

本仓库**不预置语料** —— 空目录起步，你自己往里喂。
想验证 RAG 链路能跑通，随便丢一个 `.md` 进去，然后问 agent：

> 在你的知识库里查一下 xxx，并告诉我你是怎么知道的

它应该调用知识库工具，并说明信息来源。
